Why VVC Office exists

Private by default.
Explicit by necessity.

VVC Office is a single-project workspace where the route, the session, the permission, and the audit trail agree before work is allowed through.

01

Protected at the route

Private HTML, CSS, JavaScript, and API responses are served through authenticated Rust handlers. The private source directory is never a public static root.

02

Permission is server-side

Granular roles are checked on every page and API operation. Hiding a control in the browser is only a presentation detail, never an authorization decision.

03

Audit is not disposable

Operational activity, views, and failed-login records can be cleared by authorized operators. Security audit events remain protected from that action.

!

A clear limitation

No system can honestly promise 100% security.

Rust reduces memory-safety risks, but authorization logic, dependencies, configuration, deployment, identity providers, and authorized users still matter. VVC Office targets OWASP ASVS Level 2 practices and documents the remaining operational work.
